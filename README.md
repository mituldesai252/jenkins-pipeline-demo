# Jenkins Pipeline Demo

This repository demonstrates a simple **Jenkins Pipeline** with build and deploy stages.

## Files Included
- `Jenkinsfile` – Defines the CI/CD pipeline
- `build.sh` – Simulates the build process
- `deploy.sh` – Simulates the deployment process

## Technologies Used
- Jenkins
- Bash scripting
- CI/CD concepts

## Usage
1. Open Jenkins
2. Create a new pipeline
3. Connect this repository
4. Run the pipeline to see build and deploy stages
